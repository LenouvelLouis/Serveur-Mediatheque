# Media Library Server
French version below / English version above
Java client-server application for managing a simple media library (subscribers and documents) with data persistence in a MySQL database.

This project was carried out as part of a software architecture assignment.  
It illustrates the separation of responsibilities between:

- a media library **server** (business logic, database access)
- a Java **client** (simple console interface)
- a MySQL **database** (subscribers, documents, loans)

---

## 🧩 Main features

- **Subscriber** management:
  - Subscriber registration (name, date of birth)
  - Management of banned subscribers (`AbonneBanisException`)
- **Document** management:
  - Document storage (`document` table)
  - Differentiation between **adult** and general public documents
  - Possible association with a borrower (`Emprunteur`)
- Business rules:
  - Verification of **age restrictions** (`RestrictionException`)
  - Concurrent management of document access (`ConcurrentDocument`)
- Persistence:
  - MySQL database described in the `mediatheque.sql` file
  - Sample data already provided (subscribers + documents)

## 🧱 Database

The mediatheque.sql script contains:

The creation of the database and main tables:

- subscriber: subscriber information (ID, name, date of birth)
- document: media library documents (ID, title, adult, borrower)
- Test data (pre-filled subscribers and documents)

To initialise the database:

1. Create a database, for example mediatheque, in MySQL.

2. Import the mediatheque.sql file via phpMyAdmin or the command line:
```
mysql -u <user> -p mediatheque < mediatheque.sql
```

# Serveur Médiathèque

Application client serveur en Java pour gérer une médiathèque simple (abonnés et documents) avec persistance des données dans une base MySQL.

Ce projet a été réalisé dans le cadre d’un travail d’architecture logicielle.  
Il illustre la séparation des responsabilités entre :

- un **serveur** de médiathèque (logique métier, accès base de données)
- un **client** Java (interface console simple)
- une **base de données** MySQL (abonnés, documents, emprunts)

---

## 🧩 Fonctionnalités principales

- Gestion des **abonnés** :
  - Enregistrement des abonnés (nom, date de naissance)
  - Gestion des abonnés bannis (`AbonneBanisException`)
- Gestion des **documents** :
  - Stockage des documents (table `document`)
  - Différenciation documents **adultes** / tous publics
  - Association éventuelle à un emprunteur (`Emprunteur`)
- Règles métier :
  - Vérification des **restrictions d’âge** (`RestrictionException`)
  - Gestion concurrente de l’accès aux documents (`ConcurrentDocument`)
- Persistance :
  - Base MySQL décrite dans le fichier `mediatheque.sql`
  - Données d’exemple déjà fournies (abonnés + documents)

## 🧱 Base de données

Le script mediatheque.sql contient :

La création de la base et des tables principales :

- abonne : informations sur les abonnés (id, nom, dateNaissance)
- document : documents de la médiathèque (id, titre, adulte, Emprunteur)
- Des données de test (abonnés et documents pré-remplis)

Pour initialiser la base :

1. Créer une base, par exemple mediatheque, dans MySQL.

2. Importer le fichier mediatheque.sql via phpMyAdmin ou la ligne de commande :
```
mysql -u <user> -p mediatheque < mediatheque.sql
```
